# TensorRuby

[English](README.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

TensorRuby is a Pure Ruby deep learning framework for CPU tensors, automatic differentiation, and small model training. Requires Ruby 2.6 or later.

## Install and run

```sh
curl -fL https://github.com/hjy0221/TensorRuby/releases/latest/download/tensorruby.gem -o tensorruby.gem
gem install --local tensorruby.gem
tensorruby run xor
```
